# Addonova 1.0.6

Released 2026-11-10.

## Added

- `browserApi` configuration with `external` and `bundle` modes.
- `--browser-api <external|bundle>` CLI option.
- Per-target aliasing of `@addonova/browser` to
  `@addonova/browser/<chrome|chromium|edge|firefox>` in bundle mode.
- `__ADDONOVA_BROWSER__` compile-time definition in bundle mode.
- `ADDONOVA_BROWSER_API_NOT_FOUND` when bundle mode is selected but the package
  cannot be resolved.
- Optional peer dependency on `@addonova/browser`.

## Changed

- `@addonova/browser` externalization is controlled by configuration rather than
  forced by the Guchho adapter.
- `addonova info` reports the active browser API mode.
- `build` and `dev` summaries show output files and sizes instead of a compact
  count.
- `info` prints an aligned key/value table.
- `validate`, `clean`, and `pack` use styled success, warning, and error output.

## Upgrade notes

- `external` remains the default, so existing projects keep their current
  behavior.
- Alias and externalization are mutually exclusive. Bundle mode never
  externalizes `@addonova/browser`.
- Install `@addonova/browser` before enabling bundle mode.

```bash
npm install @addonova/browser
addonova doctor
```

## Example

```ts
import { defineConfig } from 'addonova';

export default defineConfig({
  browsers: ['chrome', 'firefox'],
  browserApi: 'bundle',
});
```

See [Switch browser API to bundle](../recipes/switch-browser-api-to-bundle.md).
