| --- | --- | --- |
| 1.0.x | `^0.2.0` | `>=20` |

## Versioning policy

- Patch releases fix bugs and documentation.
- Minor releases add backward-compatible features.
- Major releases may change configuration, exports, or defaults.
- Error codes are stable within a major version.

For changes, see [Release notes](../release-notes/README.md).
